# TaskFlow
### Aplicación sencilla para administrar tareas de un equipo

## Descripción
TaskFlow es una aplicación pensada para que los equipos organicen, asignen y hagan seguimiento a sus tareas de forma sencilla y colaborativa.

## Funcionalidades
- Registro de tareas
- Edición de tareas
- Eliminación de tareas
- Asignación de tareas a usuarios
- Visualización del estado de cada tarea

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript
- Node.js
- MongoDB

## Requisitos
- Tener instalado Node.js (versión 16 o superior)
- Tener una cuenta de MongoDB Atlas o MongoDB local
- Conexión a internet para instalar dependencias
